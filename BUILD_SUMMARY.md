## Quick Start

### 1. Install Dependencies
```bash
cd F:\Portofolio\web
npm install
```

### 2. Start Development Server
```bash
npm run dev
```

### 3. Open in Browser
```
http://localhost:3000
```

## Build for Production

```bash
npm run build
npm start
```
